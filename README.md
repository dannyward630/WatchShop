## Product search and filters

The shop includes a client-side discovery panel for the static catalog:

- Keyword search across brand, description, category, material, dial color, and price metadata
- Filters for category, brand, price range, and strap material
- Active filter summary with a one-click reset
- Empty-state messaging when no watches match the current criteria

Because this repository is a static HTML/CSS/JavaScript site, the current implementation runs entirely in the browser and does not require a backend or database.
